The best meal I ever had was a bowl of hand-pulled noodles at a midnight stall in Chengdu — broth so hot it fogged my glasses, eaten standing up, not wanting it to end. One concrete moment instead of general praise: a named dish, a place, a texture and a smell, all inside a single sentence that reads aloud well. The program scores a small table of candidate one-liners on fit, humour and punch, picks the best one, checks it against the competition's gate, and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
